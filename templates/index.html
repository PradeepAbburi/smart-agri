About Project

Platform Overview

Bridging machine learning and agricultural operations for optimized harvest outputs

ℹ️ Project Mission

The Smart Agricultural Intelligence Platform is designed to help agricultural planners, farmers, and students evaluate factors affecting crop output. By utilizing advanced Regression models trained on historical data sheets, we predict estimated crop yields (Quintals per Acre) and deliver actionable agronomic advice.

This platform features automated validation of soil chemical composition (N-P-K), macro environmental factors, and historical prediction saving for comparative research.

⚙️ Data Science Engine

  • Decision Tree Regressor: A lightweight regression tree configured for high interpretability and step-wise splits.
  • Random Forest Regressor: An ensemble model aggregating multiple estimators to minimize variance and secure peak prediction accuracy.
  • Feature Importance Analysis: Dynamic calculation of feature weights to highlight how Rainfall, Temp, and Nutrients scale the yield.
